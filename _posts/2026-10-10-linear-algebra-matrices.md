初学线性代数时，矩阵看起来就是一堆数字排成方阵，乘法规则又长又难记。换一个视角会舒服很多：**矩阵是一个变换的说明书。**

## 向量先要有画面

把二维向量 `(x, y)` 想成平面上的一个箭头。矩阵 `A` 的作用，是把每个箭头搬到新位置。矩阵的每一列，其实记录了"坐标轴上的单位箭头被搬到了哪里"：

```text
A = [ 2  0 ]      列 1 = (2, 0)  ← 原来的 (1,0) 去哪儿了
    [ 0  3 ]      列 2 = (0, 3)  ← 原来的 (0,1) 去哪儿了
```

所以这个矩阵把横向拉长 2 倍、纵向拉长 3 倍。**看列，比看元素更快看懂一个矩阵在做什么。**

## 矩阵乘法＝先做后做

`AB` 的意思是：先施加 `B`，再施加 `A`（从右往左读，和函数复合 `A(B(x))` 一致）。

这立刻解释了两件事：

- **为什么 `AB` 一般不等于 `BA`**。先旋转再拉伸，和先拉伸再旋转，结果不同。
- **为什么顺序那么重要**。变换有先后，交换就换了意思。

## 行列式：面积被放大的倍数

`det(A)` 的几何含义是：这个变换把单位面积放大（或缩小）了多少倍。

- `det(A) = 2`：所有面积变成 2 倍
- `det(A) = 0`：面积被压成了 0，说明整个平面塌到一条线或一个点上，信息丢失了，矩阵不可逆
- `det(A) < 0`：面积倍数还要带上"翻转"方向

这就把"行列式为 0 则不可逆"从一条记忆变成了一个画面：**压扁了就没法还原。**

## 特征向量：方向不变的那些箭头

大多数箭头被矩阵转过方向，但总有一些只被拉长缩短、方向不变：

```text
A v = λ v
```

`v` 是特征向量，`λ` 是特征值。它们的用处是把复杂的变换拆成一串简单的伸缩。

## 一个 2×2 的算例

```text
A = [ 2  0 ]      det(A) = 2 × 3 − 0 × 0 = 6
    [ 0  3 ]
```

面积放大 6 倍。特征向量就是 (1, 0) 和 (0, 1)，特征值分别是 2 和 3——因为坐标轴方向本来就只被拉伸，没有被转动。

## 我现在的理解顺序

1. 矩阵 = 变换，先看列，知道坐标轴被搬到哪
2. 乘法 = 复合变换，所以不满足交换律
3. 行列式 = 面积倍数，为 0 意味着不可逆
4. 特征值 = 变换的"固有伸缩率"，是分解变换的入口

一旦把矩阵读成动作而不是表格，很多定理就不再需要死记了。
