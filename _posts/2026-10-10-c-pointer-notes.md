学 C 语言时最别扭的一步，是从"变量就是名字"换成"变量住在内存的某个地址上"。这篇笔记把我自己想通的过程写下来。

## 变量有地址

声明一个变量，编译器就在内存里划一块地方给它，这块地方有一个编号，就是地址。

```c
#include <stdio.h>

int main(void) {
    int n = 42;
    printf("值 = %d\n", n);
    printf("地址 = %p\n", (void *)&n);
    return 0;
}
```

`&n` 读作"n 的地址"，`%p` 用来打印地址。这里的关键是：**值**和**地址**是两种不同的东西，`n` 给你值，`&n` 给你地址。

## 指针是存放地址的变量

既然地址也是一个数，就可以把它存进变量里，这种变量叫指针。声明时用 `*` 表示"我存的是 `int` 的地址"。

```c
int n = 42;
int *p = &n;   /* p 里存的是 n 的地址 */

printf("%d\n", *p);   /* 42：顺着 p 找到那块内存，取出值 */
*p = 7;               /* 顺着 p 找到那块内存，写入 7 */
printf("%d\n", n);    /* 7：n 确实被改了 */
```

`*p` 这个动作叫**解引用**。上面两行是同一块内存的两个视角：`n` 是它的名字，`*p` 是通过地址访问它。

一句话区分两个符号：

- `&` 取地址：`p = &n`
- `*` 解引用：`*p` 是那块内存里的值

## 最容易踩的三个坑

**一、指针没初始化就解引用。**

```c
int *p;      /* 里面是垃圾值 */
*p = 5;      /* 未定义行为：可能崩溃，也可能悄悄改坏别的数据 */
```

野指针不会稳定报错，这比报错更麻烦。

**二、把地址当成值打印。** `printf("%d", p)` 是错的，地址要用 `%p` 并转成 `void *`。

**三、分不清 `int *p` 和 `*p`。** 前者在声明里，意思是"p 是指针"；后者在表达式里，意思是"取出 p 指向的值"。同一个符号，两个场合。

## 数组和指针的关系

数组名在多数表达式里会退化成指向首元素的指针，所以下面两种写法等价：

```c
int a[3] = {10, 20, 30};
printf("%d\n", a[1]);      /* 20 */
printf("%d\n", *(a + 1));  /* 20：a 退化成 &a[0]，加 1 走一个 int 的宽度 */
```

但要注意：**指针不是数组**。数组名不能被赋值，`sizeof(a)` 得到整个数组的字节数，而 `sizeof(p)` 只是一个指针的大小。

## 我现在的心智模型

把内存想成一条很长的走廊，每个房间有门牌号：

- 变量 = 住在某号房间里的东西
- `&变量` = 读出这个房间的门牌号
- 指针 = 一张写着门牌号的纸条
- `*指针` = 拿着纸条找到房间，进去看或改

想清楚这四行，函数传参为什么"改不了外面的值"也变得自然了：C 按值传参，传的是纸条的副本，改副本上的门牌号当然影响不到外面——除非你拿着纸条进房间去改房间里的东西。
