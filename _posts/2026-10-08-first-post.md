这是我的第一篇文章。

我想用一个简单的页面，记录正在学习的东西、做过的小项目，以及一些不想忘记的想法。之前笔记散在好几个地方：纸质本子、聊天记录、随手开的文档。写博客等于把它们收到一个自己能随时打开的地方。

## 我想记录什么？

- 学到的新概念，尤其是那种"看完好像懂了、合上书又说不清"的
- 做项目时遇到的问题，以及最后是怎么绕过去的
- 读过的文章和书里值得留下的句子
- 下一步想尝试的事情

## 为什么选择静态站点

这个博客没有数据库，也没有前端框架。文章是 Markdown 文件，交给 Jekyll 生成 HTML，再由 GitHub Actions 自动发布到 GitHub Pages。好处是：

1. **写作时只关心内容**。不用打开编辑器窗口，也不用等本地服务器。
2. **版本可回溯**。每一次修改都是一次提交，写错了可以退回去。
3. **几乎没有维护成本**。没有服务器要续费，没有依赖需要升级。

在线修改也可以：在 GitHub 网页上新建一个 `.md` 文件，提交后几分钟页面就会更新。

## 接下来

先把课程笔记整理成文章，再慢慢补上自己的小项目。以后新增文章只需要在 `_posts` 里复制一份文件，改文件名、标题和正文。
